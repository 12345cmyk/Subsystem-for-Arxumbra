3. Выполнена глубокая экстремальная оптимизация `src/main.rs` (`647` → `630` строк, `33 885` → `33 045` байт):
   - Константы `background_size`, `low_power` и указатель функции `smootherstep: fn(f32) -> f32` вынесены до `App::new()`, устранив дублирование полинома `t * t * t * (t * (t * 6.0 - 15.0) + 10.0)` (`grep -F -c '6.0 - 15.0' src/main.rs == 1`).
   - Геометрия окна (`width`, `height`, `panel_width`, `panel_open_x`, `panel_closed_x`, `cursor_extent`, `cover`, `cursor_limit`) вычисляется один раз за тик в регистрах без изменяемых полей замыкания (что исключает ошибку компиляции `-D unused-assignments` при `#![deny(warnings)]` в CI).
   - Замыкания `select_level`, `build_image` и `alpha_mode` типизированы как явные указатели функций `fn(...) -> ...` (higher-ranked по времени жизни `&basisu::Transcoder<'static>`), а потоки `std::thread::scope` захватывают `background_ref` и `menu_ref` через `move ||`, полностью устраняя конфликт времён жизни замыканий в `rustc`.
   - Кинематика курсора (`(-delta / 0.045).exp()`) полностью пропускается в состоянии покоя (`direction == Vec2::ZERO && cursor_velocity == Vec2::ZERO`) с отсечением денормализованных скоростей (`< 1e-4`), а при движении курсора мутируется только `Transform` без лишней записи `sprite.custom_size` (`Changed<Sprite>` не инвалидируется).
   - Транскодирование цепочки mip-уровней и сборка `bevy::image::Image` объединены в единое замыкание `build_image` с предвычислением размеров уровней на стеке (`[0usize; 16]`, побитовый расчёт `((w + 3) >> 2) * ((h + 3) >> 2) << 4`), при этом `background` и `menu` декодируются в рабочих потоках `std::thread::scope`, а `cursor` декодируется прямо на вызывающем главном потоке без накладных расходов на создание третьего потока ОС.
4. Время холодного параллельного декодирования BC7 сократилось на **44.9%** при `1920×1080` (`79.788 мс` → `43.925 мс`) и на **32.5%** при `3840×2160` (`344.232 мс` → `232.227 мс`).

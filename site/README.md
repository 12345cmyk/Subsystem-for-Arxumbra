# GitHub Pages

Статическая страница проекта: https://12345cmyk.github.io/Subsystem-for-Arxumbra/

Workflow `.github/workflows/pages.yml` публикует содержимое `site/` после
изменений страницы в `master`. В Settings → Pages должен быть выбран
источник **GitHub Actions**. Также доступен ручной запуск workflow.
Изменения из рабочей ветки нужно сначала объединить с `master`.

## Фон

По выбору владельца используется внешнее изображение Google Drive:
https://drive.google.com/file/d/1Q5QH-sdlCeAQ2_dby7veBgO0btfzLtUK/view

Файл должен быть изображением и иметь доступ «Все, у кого есть ссылка».
Страница использует endpoint `lh3.googleusercontent.com` для показа изображения,
а не HTML-страницу просмотра Drive. Доступность endpoint из среды разработки
проверить не удалось. Google может ограничивать внешнюю загрузку; в случае
ошибки страница показывает уведомление и ссылку на исходный файл.
Для независимости от Google Drive можно позднее сохранить файл в `site/`
и заменить `src` у `#background` относительным путём.

Фон заполняет экран без искажения пропорций (`object-fit: cover`),
поэтому края изображения могут обрезаться на узких экранах.

Локальная проверка: `python3 -m http.server 8000 --directory site`.
